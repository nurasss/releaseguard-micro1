# ReleaseGuard submission bundle

This directory is a curated, redacted selection for review. It contains
the 12-case offline-fixture baseline/final simulation and comparison,
ablations, representative Analyzer and Verifier trajectories, the case 12
report, the executed removed experiment, quality-gate output, official LLM
status, and a walkthrough video. The offline numbers are explicitly not
official Gemini measurements; the failed live attempt is retained separately.
Local runtime directories and secrets are excluded by the ZIP packager.
